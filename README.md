# Portfolio d'Antonella Tamadaho

Page unique en Next.js + Tailwind. Aucune variable d'environnement requise.

```bash
npm install
npm run dev     # http://localhost:3000
npm run build
```

Déploiement : importer le dépôt dans Vercel et valider.
Contenu : `app/page.tsx` · Styles : `app/globals.css` · Titre et description : `app/layout.tsx`.
